### エスケープ文字

#### 正規表現の中で+(プラス)や*(アスタリスク)や?(クエスチョン)の様な特殊記号を記号1文字として表す場合は、文字の前に\(バックスラッシュ)を付けてエスケープする。

| エスケープ文字 | 説明 |
| --- | --- |
| \d | 数字1文字 |
| \w | 文字、数字、_(アンダースコア)1文字 |
| \s | スペース、タブ |
| \D | 数字以外の1文字 |
| \W | 文字、数字、_(アンダースコア)以外の1文字 |
| \S | スペース、タブ以外の1文字 |

#### `[ ](角括弧)`で文字を囲むことでその中の1文字を表す。

| 例 | 説明 |
| --- | --- |
| `[a9あ]` | ‘a’または‘9’または‘あ’1文字 |
| `[a-z]` | 小文字の英字1文字 |
| `[0-9]` | 半角数字1文字 |
| `[a-zA-Z]` | アルファベット1文字 |

#### `[ ](角括弧)`の中に^(ハット)文字でその文字以外の1文字を表す。

| 例 | 説明 |
| --- | --- |
| `[^0-9]` | 数字以外の1文字 |
| `[^a-zA-Z]` | アルファベット以外の1文字 |

#### .(ドット)で改行以外の1文字を表す

| 例 | 説明 |
| --- | --- |
| abc. | abcの後に改行以外の1文字が続く文字列 |

#### ^(ハット)で文字列の先頭を表す

| 例 | 説明 |
| --- | --- |
| `^id[0-9]` | idから始まって数字1文字が続く |

#### $(ドル記号)で文字列の末尾を表す

| 例 | 説明 |
| --- | --- |
| `[0-9]point$` | 0-9の数字1文字とpointで終わる文字列 |

#### ^$ 空行にマッチする


#### *(アスタリスク)で直前の一文字を0回以上繰り返し

| 例 | 説明 |
| --- | --- |
| abc* |  |

#### +(プラス)で直前の一文字を1回以上繰り返し

| 例 | 説明 |
| --- | --- |
| abc+ |  |

#### ?(クエスチョン)で直前の一文字を0回/1回繰り返し

| 例 | 説明 |
| --- | --- |
| abc? |  |


#### {n}(波括弧)で数字を囲むことで直前の一文字をn回繰り返しを表す

| 例 | 説明 |
| --- | --- |
| {n, m} | 直前の文字をn〜m回繰り返し |
| {n,} | n回以上 |
| {,m} | m回以下 |
| `[a-z]{3}` |  |
| `[a-z]{3, 5}` | |

#### |(パイプ)でまたはを表す

| 例 | 説明 |
| --- | --- |
| `[0-9] | [a-z]` | 数字の1文字か小文字の英字1文字 |

#### ()(丸括弧)で文字列を囲むことでグループ化できる

| 例 | 説明 |
| --- | --- |
| `(\d\d\d)-(\d\d\d\d)-(\d\d\d\d)` | 090-1234-1234 |
| `(beer){3}` | beerbeerbeer |
| `my (vodka\|wine)` | my vodkaかmy wine |
