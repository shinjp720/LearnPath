# 正規表現 <a id="top" data-name="TOP"></a>

正規表現とは、文字列のパターンを表現するための記法で、文字列の検索・抽出、置換、検証 (バリデーション) などを行うために使用する。<br>
多くの言語や環境でサポートされている。

---

## 基本

正規表現は次の要素の組み合わせ。

```
[文字] + [量] + [条件]
```

### 文字

| 表現 | 意味 |
| --- | --- |
| a | 文字aとマッチ |
| abc | "abc"とマッチ |
| `cat|dog` | "cat" または "dog" とマッチ |
| . | 改行以外の任意の1文字とマッチ |

### 文字クラス

特定の文字が一致すべき文字の集合を定義する構文。<br>
\[&nbsp;\] で囲むか、ショートハンド (\dなど) で文字列から抽出する。

| 表現 | 意味 |
| --- | --- |
| `[abc]` | aかbかc1文字 |
| `[a-z]` | 小文字アルファベット1文字 |
| `[A-Z]` | 大文字アルファベット1文字 |
| `[0-9]` | 数字1文字 |
| `[^abc]` | a, b, c以外の1文字 |
| `[^0-9]` | 数字以外の1文字 |

### ショートハンド

よく使われる文字クラスを短く表現するための省略記法

| ショートハンド | 文字クラスでの表現 | 意味 |
| --- | --- | --- |
| \d | `[0-9]` | 数字1文字 |
| \D | `[^0-9]` | 数字以外の1文字 |
| \w | `[a-zA-Z0-9_]` | 任意の英数字とアンダーバー1文字 |
| \W | `[^a-zA-Z0-9_]` | 任意の英数字とアンダーバー以外の1文字 |
| \s | `[ \t\n\r\f\v]` | スペースや改行などの空白文字1文字 |
| \S | `[^ \t\n\r\f\v]` | 空白文字以外の1文字 |

---

## 繰り返し (量指定子)

| 表現 | 意味 |
| --- | --- |
| * | 0回以上 |
| + | 1回以上 |
| ? | 0か1 |
| `{n}` | n回 |
| `{n,}` | n回以上 |
| `{n,m}` | n～m回 |

---

## 位置指定 (アンカー)

| 表現 | 意味 |
| --- | --- |
| ^ | 行頭 |
| $ | 行末 |
| `\b` | 単語境界 |
| `\B` | 単語境界以外 |

<pre><code class="caution">単語境界は ASCII のみと認識したほうがいい</code></pre>

## グループと選択

文字クラス \[&nbsp;\] が1文字だったのに対して、グループ (&nbsp;) はひとかたまりの文字列として扱う。

グループ内で \|(パイプ) を使うと または という意味になる。

| 表現 | 意味 |
| --- | --- |
| `(apple|windows)` | apple か windows |

### キャプチャ

グループ化すると自動的にキャプチャされてメモリに置かれるので、後から1番目のグループ、2番目のグループのように再利用できる。<br>
非キャプチャを指定することによってキャプチャされなくなり、メモリの節約や または を使うためにグループを使える。

| 表現 | 意味 |
| --- | --- |
| (abc) | キャプチャグループ |
| (?:abc) | 非キャプチャグループ |

### キャプチャ参照

| 表現 | 意味 |
| --- | --- |
| `\1` | 1番目のキャプチャ |
| `\2` | 2番目のキャプチャ |

参照は言語による。

| 表現 | 意味 |
| --- | --- |
| .* | 貪欲 (最大一致) |
| .+? | 非貪欲 (最小一致) |
| .+? | 最小1文字 |

| --- | --- |

| `\*` | * |

# 正規表現まとめ

## 基本

| 記号  | 意味           | 例     |
| --- | ------------ | ----- |
| `a` | 文字そのもの       | `abc` |
| `.` | 任意の1文字（改行除く） | `a.c` |
| `\` | 特殊文字のエスケープ   | `\.`  |

---

## 文字クラス

### 数字

| 記号   | 意味      |
| ---- | ------- |
| `\d` | 数字1文字   |
| `\D` | 数字以外1文字 |

#### 例

```regex
\d+
```

一致:

```text
123
2025
```

---

### 英数字

| 記号   | 意味          |
| ---- | ----------- |
| `\w` | 英数字と `_`    |
| `\W` | 英数字と `_` 以外 |

#### 例

```regex
\w+
```

一致:

```text
hello
abc123
test_value
```

---

### 空白

| 記号   | 意味   |
| ---- | ---- |
| `\s` | 空白文字 |
| `\S` | 空白以外 |

---

### 任意の文字集合

```regex
[abc]
```

一致:

```text
a
b
c
```

---

```regex
[a-z]
```

一致:

```text
a
b
z
```

---

```regex
[^0-9]
```

意味:

```text
数字以外
```

---

## 回数指定（量指定子）

| 記号      | 意味      |
| ------- | ------- |
| `*`     | 0回以上    |
| `+`     | 1回以上    |
| `?`     | 0回または1回 |
| `{n}`   | n回      |
| `{n,}`  | n回以上    |
| `{n,m}` | n～m回    |

### 例

```regex
\d{4}
```

一致:

```text
2025
1999
```

---

## 位置指定

| 記号   | 意味     |
| ---- | ------ |
| `^`  | 行頭     |
| `$`  | 行末     |
| `\b` | 単語境界   |
| `\B` | 単語境界以外 |

### 例

```regex
^Hello
```

一致:

```text
Hello World
```

---

```regex
World$
```

一致:

```text
Hello World
```

## グループ化

### キャプチャ

* グループ化
* 後方参照

---

### 非キャプチャ

```regex

```

用途:

* グループ化のみ

---

## OR条件

```regex
cat|dog
```

一致:

```text
cat
dog
```

---

## 後方参照

```regex
(\w+)\s+\1
```

一致:

```text
hello hello
test test
```

---

## 先読み

### 肯定先読み

```regex
\d+(?=円)
```

一致:

```text
100円
500円
```

取得:

```text
100
500
```

---

### 否定先読み

```regex
\d+(?!円)
```

意味:

```text
後ろに円が続かない数字
```

---

## 後読み

### 肯定後読み

```regex
(?<=\$)\d+
```

一致:

```text
$100
```

取得:

```text
100
```

---

### 否定後読み

```regex
(?<!\$)\d+
```

意味:

```text
前に $ がない数字
```

---

## 貪欲・非貪欲

### 貪欲（Greedy）

```regex
<.*>
```

対象:

```html
<div>abc</div>
```

取得:

```html
<div>abc</div>
```

---

### 非貪欲（Lazy）

```regex
<.*?>
```

取得:

```html
<div>
```

# よく使うパターン

## 数値

```regex
^\d+$
```

---

## 郵便番号

```regex
^\d{3}-\d{4}$
```

---

## 日付

```regex
^\d{4}-\d{2}-\d{2}$
```

---

## メールアドレス（簡易）

```regex
^[\w.-]+@[\w.-]+\.[A-Za-z]{2,}$
```

---

## URL（簡易）

```regex
^https?://
```

---

# 注意点

* `.` は改行に一致しない
* `[]` の中では意味が変わる記号がある
* `\` のエスケープ忘れに注意
* `*` と `+` を混同しやすい
* 貪欲マッチによる取りすぎに注意
* 言語ごとに対応していない機能がある（特に後読み）

---

# よく使う覚え方

* `d` → digit
* `w` → word
* `s` → space
* `^` → 始まり
* `$` → 終わり
* `+` → 1個以上
* `*` → 0個以上
* `?` → あってもなくてもよい
