# vimium <a id="top" data-name="TOP"></a>

Vimium は、キーボードだけで Web の閲覧を操作するための、ブラウザの拡張機能。Vim に近いキー操作で、スクロール、リンクのクリック、タブの切り替え、ページ内の検索ができる。

Chrome の拡張機能として作られていて、Firefox 版もある。マウスに手を伸ばさずに、ほとんどの操作をキーで行える点が、最大の特徴。キー一覧は、ブラウザ上で `?` を押すと、いつでも表示できる。

---

## 概要 <a id="overview" data-name="概要"></a>

### 特徴

| 特徴 | 内容 |
| --- | --- |
| キーボード操作 | スクロール、タブ、履歴、検索を、キーで操作する |
| リンクヒント | リンクにラベルを表示して、ラベルの文字を入力してクリックする (<a href="#link-hints">リンクヒント</a>) |
| ボムニバー (Vomnibar) | URL、ブックマーク、履歴、開いているタブを、キーボードから検索して開く |
| キーのカスタマイズ | `map` と `unmap` で、キーの割り当てを変更できる (<a href="#customize">キーマッピングのカスタマイズ</a>) |
| 設定の同期 | 設定を、複数のコンピューターで同期できる |

### 対応ブラウザ

| ブラウザ | 入手先 |
| --- | --- |
| Chrome | Chrome ウェブストア |
| Firefox | Firefox Add-ons |

### Vim との違い

キー操作は Vim に似ているが、同じではない。Vim の感覚で押すと、違う動作になるキーがある。

| キー | Vim | Vimium |
| --- | --- | --- |
| `u` | 取り消し (undo) | 半ページ上へスクロール |
| `d` | 削除の操作 | 半ページ下へスクロール |
| `x` | 1文字を削除 | 現在のタブを閉じる |
| `X` | 前の1文字を削除 | 閉じたタブを復元 |

`gg`、`G`、`/`、`n`、`N`、`h`、`j`、`k`、`l` は、Vim と近い動作になる。Vim 自体のキー操作は、Vim のドキュメントを参照。

<pre><code class="caution">このドキュメントは、Vimium 2.x を前提にしている (Firefox Add-ons の最新版は 2.3.1、2025年11月)。
キーの割り当てや、設定の項目名は、バージョンやブラウザで異なることがある。手元の版の正しい一覧は、? キーで表示されるヘルプで確認する。</code></pre>

## 導入 <a id="introduction" data-name="導入"></a>

| 手順 | 内容 |
| --- | --- |
| 1 | Chrome ウェブストア (Chrome) か、Firefox Add-ons (Firefox) から、Vimium を追加する |
| 2 | 任意のページで `?` を押して、ヘルプ (キーの一覧) を表示する |
| 3 | オプションページを開く。ヘルプのリンク、または、拡張機能の管理ページの Vimium の横のボタンから開く |

拡張機能の管理ページは、Chrome では `chrome://extensions`、Firefox では `about:addons`。

### 新しいタブページでの動作

Vimium は、Vimium 自身の `t` (新しいタブを開くコマンド) で開いたタブでは動作する。<br>
Ctrl+T などの、ブラウザの標準のショートカットで開いた新しいタブでも使うには、補助の拡張機能 (Vimium New Tab Page) が必要になる、と README に書かれている。

<pre><code class="tips">新しいタブをキーボードで開くときは、Ctrl+T ではなく、Vimium の t を使うと、そのタブでも Vimium が動く。</code></pre>

## 基本 <a id="basic" data-name="基本"></a>

### キーの表記

ヘルプやオプションページでは、修飾キーを `<c-x>` のような形で書く。

| 表記 | 意味 |
| --- | --- |
| `<c-x>` | Ctrl + x |
| `<a-x>` | Alt + x |
| `<m-x>` | Meta + x (Mac では Command) |
| `X` | Shift + x。大文字で書く |
| `<c-X>` | Ctrl + Shift + x |
| `<left>`、`<right>`、`<up>`、`<down>` | 矢印キー |
| `<f1>`〜`<f12>` | ファンクションキー |
| `<space>` | スペースキー |

### 回数の指定

コマンドの前に数字を付けると、その回数だけ繰り返す。

| 入力 | 動作 |
| --- | --- |
| `5t` | 新しいタブを、5つ続けて開く |
| `3W` | 3つのタブを、1つの新しいウィンドウに移動する |
| `2g0` | 左から2番目のタブへ移動する |
| `999r` | 現在のウィンドウの、すべてのタブをリロードする |

### Esc の役割

`Esc` (または `<c-[>`) は、入力の途中のコマンドを取り消す。挿入モードと検索モードを抜けるときにも使う。

<pre><code class="tips">キー入力が思ったように動かないときは、まず Esc を押して、入力途中の状態とモードをリセットする。</code></pre>

### ページナビゲーション

| キー | 説明 |
| --- | --- |
| `j` | 下へスクロール |
| `k` | 上へスクロール |
| `h` | 左へスクロール |
| `l` | 右へスクロール |
| `gg` | ページの最上部へジャンプ |
| `G` | ページの最下部へジャンプ |
| `d` | 半ページ下へスクロール |
| `u` | 半ページ上へスクロール |
| `zH` | ページの左端までスクロール |
| `zL` | ページの右端までスクロール |
| `r` | ページをリロード |
| `R` | キャッシュを使わずに、ページをリロード (ハードリロード) |
| `gs` | ページのソースを表示 |
| `yy` | 現在のページの URL をクリップボードへコピー |
| `p` | 現在のタブで、クリップボードの URL へ移動 |
| `P` | 新しいタブで、クリップボードの URL へ移動 |
| `gu` | URL の階層を、1つ上へ移動 |
| `gU` | URL の階層の、ルートへ移動 |
| `]]` | 「next」や「>」のラベルが付いたリンクへ移動 (ページ分割されたサイトで使う) |
| `[[` | 「previous」や「&lt;」のラベルが付いたリンクへ移動 |

| `v` | ヴィジュアルモード |

| `gi` | ページ上の、最初のテキスト入力にフォーカス |
| `gf` | ページの、次の frame にフォーカス |
| `gF` | ページの、メイン/トップ frame にフォーカス |

### ボムニバー (Vomnibar) を使う

| キー | 説明 |
| --- | --- |
| `o` | 現在のタブで、URL、ブックマーク、履歴から開く |
| `O` | 新しいタブで、URL、ブックマーク、履歴から開く |
| `b` | 現在のタブで、ブックマークを開く |
| `B` | 新しいタブで、ブックマークを開く |
| `T` | 開いているタブを検索して、切り替える |
| `ge` | 現在の URL を編集する |
| `gE` | 現在の URL を編集して、新しいタブで開く |

<pre><code class="tips">ボムニバーでは、検索エンジンのショートカットを使える。オプションページで登録すると、o から、ブラウザのアドレスバーと同じ要領で、検索できる。</code></pre>

### 文字列を検索

| キー | 説明 |
| --- | --- |
| `/` | 検索モード (文字列を入力して Enter で検索、Esc で中止) |
| `n` | 次の検索結果に進む |
| `N` | 前の検索結果に戻る |

### 履歴

| キー | 説明 |
| --- | --- |
| `H` | 前の履歴 (戻る) |
| `L` | 次の履歴 (進む) |

### タブ

| キー | 説明 |
| --- | --- |
| `t` | 新しいタブを開く |
| `J`、`gT` | 左のタブへ |
| `K`、`gt` | 右のタブへ |
| `^` | 前にアクセスしたタブへ |
| `g0` | 一番左のタブへ (`2g0` のように回数を付けると、n 番目のタブへ) |
| `g$` | 一番右のタブへ |
| `yt` | 現在のタブを複製する |
| `Alt+p` | タブをピン留め (もう一度押すと、解除) |
| `Alt+m` | タブをミュート |
| `x` | タブを閉じる |
| `X` | 閉じたタブを復元 |
| `W` | 現在のタブを、新しいウィンドウへ移動 |

<pre><code class="tips">J と K は、タブの並びの方向に対応する。J が左、K が右になる。スクロールの j (下)、k (上) と、混同しないように注意する。</code></pre>

## リンクヒント <a id="link-hints" data-name="リンクヒント"></a>

`f` を押すと、クリックできる要素に、短い文字のラベル (ヒント) が表示される。ラベルの文字を入力すると、その要素がクリックされる。マウスを使わずに、リンクやボタンを操作できる。

| キー | 説明 |
| --- | --- |
| `f` | リンクを、現在のタブで開く |
| `F` | リンクを、新しいタブで開く |
| `<a-f>` | 複数のリンクを、新しいタブで、続けて開く |
| `yf` | リンクの URL を、クリップボードへコピーする |

<pre><code class="tips">ヒントを使わずに中止するときは、Esc を押す。ヒントの文字の選び方や、リンクの文字で絞り込む方式は、オプションページで設定できる。</code></pre>

---

## マーク <a id="marks" data-name="マーク"></a>

ページ内の位置に名前を付けて、あとから、その位置へ戻れる。

| キー | 説明 |
| --- | --- |
| `ma` | ローカルマーク a を設定する (現在のページ内) |
| `mA` | グローバルマーク A を設定する (別のタブからも戻れる) |
| <code>&#96;a</code> | ローカルマーク a の位置へ移動する |
| <code>&#96;A</code> | グローバルマーク A の位置へ移動する |
| <code>&#96;&#96;</code> | 直前のジャンプの、前の位置へ戻る |

直前のジャンプとは、`gg`、`G`、`n`、`N`、`/`、マークへの移動のことである。

## モード <a id="modes" data-name="モード"></a>

Vimium には、キーの扱いが変わる、複数のモードがある。

| モード | 入り方 | 内容 |
| --- | --- | --- |
| ノーマル | 通常の状態 | Vimium のコマンドを、そのまま使える |
| インサート | `i` | Esc で抜けるまで、すべてのコマンドが無効になる |
| 検索 | `/` | 文字列を入力して、Enter で検索する。Esc で中止する |
| ヴィジュアル | `v` | テキストを選択する。`p` / `P` で、クリップボードの内容へ移動し、`y` でコピーする |
| ヴィジュアルライン | `V` | 行単位で選択する |

<pre><code class="tips">キーボードで文字を入力するページでは、インサートモードにすると、Vimium のキーと衝突しない。i で入って、Esc で戻る。</code></pre>

## キーマッピングのカスタマイズ <a id="customize" data-name="キーマッピング"></a>

オプションページの「Custom key mappings」に、1行に1つずつ、コマンドを書く。

| 書式 | 内容 |
| --- | --- |
| `map key command` | キーを、Vimium のコマンドに割り当てる。ブラウザの既定の動作 (ある場合) を、上書きする |
| `unmap key` | キーの割り当てを解除して、ブラウザの既定の動作 (ある場合) を戻す |
| `unmapAll` | Vimium の既定の割り当てを、すべて解除する。初期状態から、自分で作り直したいときに使う |

行の先頭に `"` か `#` を付けると、コメントになる。

```text
# r を、別のキーに移す例
unmap r
map R reload

# Ctrl+d を、ページのスクロールに使う例
map <c-d> scrollPageDown
```

使えるコマンドの名前は、オプションページの、キー入力欄の近くにある「Show available commands」のリンクで確認できる。コマンド名は、説明の右側の、括弧の中に表示される。

<pre><code class="caution">map で、Ctrl+d のようなブラウザの標準のショートカットを割り当てると、ブラウザ側の動作 (Ctrl+d のブックマーク登録など) が、使えなくなる。
元に戻すには、unmap &lt;c-d&gt; のように、割り当てを解除する。</code></pre>

## 設定 <a id="options" data-name="設定"></a>

オプションページで設定できる、主な項目。

| 項目 | 内容 |
| --- | --- |
| Custom key mappings | キーの割り当て (<a href="#customize">キーマッピングのカスタマイズ</a>) |
| 除外リスト (Excluded URLs) | URL のパターンを指定して、そのページでは Vimium を無効にする |
| 検索エンジン (Search engines) | ボムニバーから使う、検索のショートカットを登録する |
| リンクヒント | ヒントの文字の選び方や、文字での絞り込みを設定する |
| スムーズスクロール | スクロールの滑らかさを、切り替える |

<pre><code class="tips">Gmail のように、独自のキーボードショートカットを持つサイトは、除外リストに登録すると、衝突を避けられる。ツールバーの Vimium のアイコンから、現在のサイトを、すばやく除外リストに追加することもできる。
項目の名前は、バージョンによって異なることがある。</code></pre>

## よくある落とし穴 <a id="pitfalls" data-name="よくある落とし穴"></a>

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| キーを押しても、何も起きない | インサートモードになっている。または、入力欄にフォーカスがある | Esc を押す |
| 一部のページで、Vimium が動かない | ブラウザの仕様で、拡張機能が動作しないページがある (ブラウザの内部ページ、ストアのページなど) | 通常のページで、動作を確認する |
| 新しいタブで、Vimium が動かない | ブラウザ標準のショートカットで開いた新しいタブは、拡張機能の対象外になる | Vimium の `t` で開く。または、補助の拡張機能を入れる |
| Gmail などの、サイト独自のショートカットと衝突する | サイトと Vimium が、同じキーを使う | 除外リストに、そのサイトを登録する |
| Ctrl+d などの、ブラウザの標準のショートカットが、効かなくなった | `map` で、同じキーを上書きしている | `unmap <c-d>` のように、割り当てを解除する |
| ページがスクロールしない | フォーカスが、別の frame にある | `gf` で frame を切り替える。または、`gF` でメイン frame に戻る |
| タブの移動が、逆に感じる | `J` が左、`K` が右の、タブの並び順に対応している | `gT` と `gt` も、同じ動作になる。キーの対応を、覚え直す |
| ヒントの文字が、リンクの文字と混ざって、入力しにくい | 文字での絞り込みが、有効になっている | オプションページで、リンクヒントの設定を変える |
