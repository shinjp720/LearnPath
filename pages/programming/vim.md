# Vim <a id="top" data-name="TOP"></a>

Vim は、ターミナルで動く、モーダルなテキストエディタである。Unix の `vi` を拡張したもので、キーボードだけで、移動、編集、検索、置換、複数ファイルの操作まで、行える。

最大の特徴は、**モード**を切り替えて使う点にある。ノーマルモードでは、キーが「文字の入力」ではなく「コマンド」になる。<br>
コマンドは、「動詞 (operator) + 範囲 (motion / text object)」という文法で組み合わせる。少ないキーを覚えれば、組み合わせで、多くの操作ができる。

SSH 先のサーバー、コンテナの中、最小構成の Linux など、ほぼすべての Unix 系環境に、`vi` か `vim` が入っている。設定ファイルを数行書くだけで、軽量なエディタとして、すぐに使える。

## 概要 <a id="overview" data-name="概要"></a>

### 特徴

| 特徴 | 内容 |
| --- | --- |
| モーダル編集 | ノーマル、挿入、ビジュアル、コマンドラインなどのモードを、切り替えて使う |
| 組み合わせの文法 | `d` (削除) + `w` (単語) = `dw` のように、動詞と範囲を組み合わせる |
| 繰り返し | `.` で、直前の変更を繰り返す。マクロと、回数指定もある |
| 軽量 | ターミナルだけで動き、起動が速い。リモート環境でも使える |
| 拡張性 | Vim script、Vim9 script、プラグイン、パッケージの仕組みがある |
| 広い互換性 | `vi` のキー操作を、ほぼ引き継いでいる |

### Vim、Neovim、vi の違い

| | vi | Vim | Neovim |
| --- | --- | --- | --- |
| 位置づけ | 元祖 (POSIX の標準) | `vi` の拡張。本ドキュメントの対象 | Vim をもとにした、再構成版 |
| 設定言語 | なし (`.exrc`) | Vim script、Vim9 script | Lua と Vim script |
| 組み込みの機能 | 最小限 | 豊富 (補完、diff、ターミナル、パッケージなど) | LSP、Treesitter、プラグイン管理 (`vim.pack`) などを内蔵 |
| 設定ファイル | `~/.exrc` | `~/.vimrc` | `~/.config/nvim/init.lua` |
| 向いている場面 | 最小環境の、緊急用 | どこでも使える、安定した環境 | 現代的な開発環境を、作り込みたいとき |

Neovim については、本ドキュメントの <a href="#neovim">Neovim との違い</a> の章で触れる。

### 向き不向き

| 向いている場面 | 向いていない場面 |
| --- | --- |
| サーバー上での、設定ファイルやログの編集 | マウス中心の、操作に慣れたい場合 |
| 大量のテキストの、一括置換や整形 | 設定なしで、IDE のような補完とデバッグがほしい場合 |
| キーボードだけで、素早く作業したい場合 | 短期間で、すべてを覚えたい場合 (学習に時間がかかる) |

<pre><code class="caution">このドキュメントは、Vim 9.2 (2026年2月14日公開) を前提にしている。9.2 では、組み込みの既定値の変更、Wayland の実験的な対応、設定ファイルの置き場所の追加などが入った。
パッチは、ほぼ毎日積まれるため、同じ 9.2 でも、細かい挙動が異なることがある。手元の版は vim --version で確認する。</code></pre>

## 導入 <a id="introduction" data-name="導入"></a>

### インストール

| 環境 | コマンド |
| --- | --- |
| Debian / Ubuntu | `sudo apt install vim` |
| Fedora | `sudo dnf install vim-enhanced` |
| macOS (Homebrew) | `brew install vim` |
| Windows (winget) | `winget install vim.vim` |

ディストリビューションが配るパッケージは、版が古いことがある。LTS のディストリビューションでは、版番号を上げずに、脆弱性の修正だけを取り込む場合もある。新しい機能が必要なときは、版を確認してから、使う。

### 版と機能の確認

```bash
vim --version
```

```text
VIM - Vi IMproved 9.2 (2026 Feb 14, compiled ...)
Included patches: 1-...
+clipboard  +python3  +terminal  ...
```

- 先頭の版番号と、`Included patches` のパッチ番号で、版を確認する。
- `+clipboard` と `-clipboard` のように、機能の有無が、一覧で出る。**クリップボードやスクリプト言語は、ビルドによって、有効かどうかが違う**。

Vim script の中で、機能や版を判定するときは、版番号ではなく、`has()` を使う。

```vim
if has('patch-9.1.1232')
  " 特定のパッチ以降で、有効な機能を使う
endif

if has('clipboard')
  " クリップボードが、使えるビルドのとき
endif
```

### 設定ファイルの場所

| ファイル・ディレクトリ | 内容 |
| --- | --- |
| `~/.vimrc` | 従来の、ユーザー設定ファイル |
| `~/.vim/` | プラグイン、色設定、ドキュメントなどの置き場 (Windows では `~/vimfiles/`) |
| `$HOME/.config/vim` | 9.2 で対応した、XDG Base Directory 準拠の置き場 |
| `$VIMRUNTIME` | 同梱されている、ランタイムファイル (読み取り専用として扱う) |

```vim
:echo $MYVIMRC
:echo $VIMRUNTIME
:version
```

`$MYVIMRC` で、実際に読み込まれている設定ファイルの、パスを確認できる。XDG の置き場と、従来の `~/.vimrc` が、両方ある場合の優先順位は、`:help` で確認する。

### チュートリアル

```bash
vimtutor
```

`vimtutor` は、30 分ほどで終わる、公式の練習用ファイルである。9.2 では、組み込みの対話的なチュートリアルのプラグインも、加わった。

### ヘルプ

| コマンド | 内容 |
| --- | --- |
| `:help` | ヘルプを開く |
| `:help {topic}` | 項目を調べる (`:help dw`、`:help 'tabstop'`) |
| `:help index` | キー操作の、全一覧 |
| `:helpgrep {pattern}` | ヘルプ全体を、検索する |
| `CTRL-]` | ヘルプ内のリンク (タグ) へ、移動する |
| `CTRL-O` | 元の位置へ、戻る |

<pre><code class="tips">オプションは 'tabstop' のように、引用符で囲んで調べる。コマンドは :help :s、挿入モードのキーは :help i_CTRL-W のように、接頭辞で区別する。
迷ったら、:help の後に CTRL-D を押すと、補完の候補が出る。</code></pre>

## モード <a id="modes" data-name="モード"></a>

### 主なモード

| モード | 入り方 | 内容 |
| --- | --- | --- |
| ノーマル (Normal) | 起動時、`Esc`、`CTRL-[` | 移動や編集の、コマンドを実行する。基本の状態 |
| 挿入 (Insert) | `i`、`a`、`o` など | 文字を入力する |
| ビジュアル (Visual) | `v`、`V`、`CTRL-V` | 範囲を選択する |
| コマンドライン (Command-line) | `:`、`/`、`?` | Ex コマンドや、検索パターンを入力する |
| 置換 (Replace) | `R` | 上書きで、文字を入力する |
| ターミナル (Terminal) | `:terminal` | 組み込みのターミナルを使う |

### 挿入モードへの入り方

| キー | 挿入する位置 |
| --- | --- |
| `i` | カーソルの前 |
| `a` | カーソルの後 |
| `I` | 行頭の、最初の非空白文字の前 |
| `A` | 行末 |
| `o` | 下に、新しい行を作る |
| `O` | 上に、新しい行を作る |
| `gi` | 前回の、挿入を終えた位置 |

### ビジュアルモードの種類

| キー | 種類 | 内容 |
| --- | --- | --- |
| `v` | 文字単位 | 文字の範囲を選ぶ |
| `V` | 行単位 | 行全体を選ぶ |
| `CTRL-V` | 矩形 (ブロック) | 長方形の範囲を選ぶ |

<pre><code class="tips">ノーマルモードに戻る操作は、とても多い。Esc が遠いときは、CTRL-[ か、設定で別のキーに割り当てる方法がある。
今どのモードにいるか分からなくなったら、Esc を 2 回押すと、ノーマルモードに戻れる。</code></pre>

## 基本操作 <a id="file-ops" data-name="基本操作"></a>

### 起動

```bash
vim file.txt              # ファイルを開く
vim +42 file.txt          # 42 行目を表示して開く
vim +/pattern file.txt    # 最初の一致の位置で開く
vim -O a.txt b.txt        # 左右に分割して開く
vim -d a.txt b.txt        # 差分を表示して開く
vim -R file.txt           # 読み取り専用で開く
vim -u NONE -N            # 設定を読まずに起動する
```

`vim -u NONE -N` は、設定ファイルを、一切読まずに起動する。**設定が原因の問題かどうかを、切り分ける**ときに使う。

### 保存と終了

| コマンド | 内容 |
| --- | --- |
| `:w` | 保存する |
| `:w {file}` | 別名で保存する |
| `:q` | 終了する (変更があると、拒否される) |
| `:q!` | 変更を捨てて、終了する |
| `:wq` | 保存して、終了する |
| `:x` | 変更があるときだけ保存して、終了する |
| `ZZ` | `:x` と同じ |
| `ZQ` | `:q!` と同じ |
| `:wa` | 開いているすべてのバッファを、保存する |
| `:qa` | すべてのウィンドウを、閉じて終了する |
| `:e!` | 最後に保存した状態に、戻す |

### ファイルを開く

| コマンド | 内容 |
| --- | --- |
| `:e {file}` | ファイルを開く |
| `:e` | 現在のファイルを、読み直す |
| `:find {name}` | `'path'` の中から、ファイルを探して開く |
| `:r {file}` | ファイルの内容を、カーソルの下に挿入する |
| `:r !{cmd}` | コマンドの出力を、カーソルの下に挿入する |
| `:w !sudo tee %` | 権限が足りないファイルを、`sudo` で保存する |

```vim
:set path+=**
:find main.rs
```

`:set path+=**` で、カレントディレクトリ以下を、再帰的に探せる。これと、`:find` のタブ補完で、簡易的なファイル検索になる。

<pre><code class="caution">:w !sudo tee % は、Vim の外のコマンドに、バッファの内容を渡して保存する。環境によっては、sudo のパスワード入力と相性が悪い。
権限が必要なファイルは、最初から sudoedit で開く方が、安全である。</code></pre>

### 取り消しとやり直し

| キー | 内容 |
| --- | --- |
| `u` | 取り消す (undo) |
| `CTRL-R` | やり直す (redo) |
| `U` | 行全体の、変更を取り消す |
| `:earlier 10m` | 10 分前の状態に、戻る |
| `:later 10m` | 10 分後の状態に、進む |
| `:undolist` | 取り消しの、ブランチ (分岐) の一覧 |

Vim の取り消しは、履歴が**木構造**になっている。`u` で戻ってから、別の編集をしても、元の変更は、消えずに、別の枝として残る。

## 移動 <a id="motion" data-name="移動"></a>

移動は、Vim の操作の基礎である。同じ移動が、削除や、コピーの、範囲指定にも使われる。

### 文字と行の移動

| キー | 内容 |
| --- | --- |
| `h` `j` `k` `l` | 左、下、上、右 |
| `0` | 行頭 |
| `^` | 行の、最初の非空白文字 |
| `$` | 行末 |
| `gg` | ファイルの先頭 |
| `G` | ファイルの末尾 |
| `{n}G` / `:{n}` | `n` 行目へ移動する |
| `H` `M` `L` | 画面の、上、中央、下 |

### 単語の移動

| キー | 内容 |
| --- | --- |
| `w` | 次の単語の先頭 |
| `b` | 前の単語の先頭 |
| `e` | 単語の末尾 |
| `W` `B` `E` | 空白で区切った、まとまり (WORD) 単位で移動する |

`w` は、英数字と記号を、別の単語として扱う。`W` は、空白だけを区切りとする。`foo.bar(baz)` のような文字列で、違いが分かる。

### 文字を探す移動

| キー | 内容 |
| --- | --- |
| `f{c}` | 行内で、右に向かって、文字 `c` へ移動する |
| `F{c}` | 行内で、左に向かって、文字 `c` へ移動する |
| `t{c}` | 行内で、`c` の手前まで移動する |
| `T{c}` | 行内で、左に向かって、`c` の後ろまで移動する |
| `;` | 直前の `f` `t` を、同じ向きで繰り返す |
| `,` | 直前の `f` `t` を、逆向きで繰り返す |

### 段落・括弧・スクロール

| キー | 内容 |
| --- | --- |
| `{` `}` | 前、次の段落 (空行の位置) へ移動する |
| `%` | 対応する括弧へ移動する |
| `(` `)` | 前、次の文へ移動する |
| `CTRL-D` / `CTRL-U` | 半画面、下、上へスクロールする |
| `CTRL-F` / `CTRL-B` | 1 画面、下、上へスクロールする |
| `zz` | カーソルの行を、画面の中央にする |
| `zt` / `zb` | カーソルの行を、画面の上、下にする |

<pre><code class="tips">hjkl を連打するより、w、f、t、検索、{ } などの、大きな移動を使う方が、速い。
数字を前に付けると、回数の指定になる。5j は 5 行下、3w は 3 単語先である。</code></pre>

## 編集 <a id="edit" data-name="編集"></a>

### 動詞 (operator) + 範囲

ノーマルモードの編集は、「動詞 + 範囲」で表す。

| 動詞 | 内容 |
| --- | --- |
| `d` | 削除する (delete) |
| `c` | 削除して、挿入モードに入る (change) |
| `y` | コピーする (yank) |
| `>` / `<` | インデントを、増やす、減らす |
| `=` | 自動で、インデントを整える |
| `gu` / `gU` | 小文字、大文字にする |
| `g~` | 大文字と小文字を、入れ替える |
| `gq` | テキストを、整形する (折り返す) |

```text
dw      カーソルから、単語の末尾までを削除する
d$      カーソルから、行末までを削除する
c2w     2 単語を削除して、挿入モードに入る
y}      次の段落の手前までを、コピーする
>j      現在行と、下の行を、インデントする
gUiw    カーソルの下の単語を、大文字にする
```

動詞を、2 回重ねると、**現在の行**が対象になる。

| キー | 内容 |
| --- | --- |
| `dd` | 行を削除する |
| `yy` | 行をコピーする |
| `cc` | 行を削除して、挿入モードに入る |
| `>>` | 行を、インデントする |
| `guu` / `gUU` | 行を、小文字、大文字にする |

### 1 文字と行の編集

| キー | 内容 |
| --- | --- |
| `x` | カーソルの下の文字を削除する |
| `X` | カーソルの前の文字を削除する |
| `r{c}` | 1 文字を、`c` に置き換える |
| `s` | 1 文字を削除して、挿入モードに入る |
| `D` | カーソルから行末までを削除する (`d$`) |
| `C` | カーソルから行末までを削除して、挿入モードに入る (`c$`) |
| `J` | 下の行を、現在の行に結合する |
| `~` | 1 文字の、大文字と小文字を入れ替える |
| `CTRL-A` / `CTRL-X` | カーソル以降の数値を、増やす、減らす |

### 貼り付け

| キー | 内容 |
| --- | --- |
| `p` | カーソルの後ろ (行単位なら下) に貼り付ける |
| `P` | カーソルの前 (行単位なら上) に貼り付ける |
| `]p` | 現在のインデントに合わせて、貼り付ける |
| `gp` / `gP` | 貼り付けた後に、カーソルを末尾の後ろへ置く |

### 挿入モード中のキー

| キー | 内容 |
| --- | --- |
| `CTRL-W` | 直前の単語を削除する |
| `CTRL-U` | 行頭まで削除する |
| `CTRL-O` | 1 回だけ、ノーマルモードのコマンドを実行する |
| `CTRL-R {reg}` | レジスタの内容を挿入する |
| `CTRL-V {code}` | 特殊文字を、そのまま入力する |
| `CTRL-T` / `CTRL-D` | インデントを、増やす、減らす |

## テキストオブジェクト <a id="text-object" data-name="テキストオブジェクト"></a>

テキストオブジェクトは、「カーソルの周りの、意味のあるまとまり」を、範囲として指定する仕組みである。動詞の後ろ (と、ビジュアルモード) で使う。

- `i` (inner) は、区切りの記号や、空白を含まない内側。
- `a` (around) は、区切りの記号や、空白も含む外側。

| オブジェクト | 内容 |
| --- | --- |
| `iw` / `aw` | 単語 |
| `iW` / `aW` | WORD (空白で区切ったまとまり) |
| `is` / `as` | 文 |
| `ip` / `ap` | 段落 |
| `i(` / `a(` (`ib` / `ab`) | `( )` の内側、外側 |
| `i{` / `a{` (`iB` / `aB`) | `{ }` の内側、外側 |
| `i[` / `a[` | `[ ]` の内側、外側 |
| `i<` / `a<` | `< >` の内側、外側 |
| `i"` / `a"` | `"` で囲んだ文字列の、内側、外側 |
| `i'` / `a'` | `'` で囲んだ文字列の、内側、外側 |
| `` i` `` / `` a` `` | バッククォートで囲んだ文字列 |
| `it` / `at` | HTML や XML のタグ |

```text
ci"     " の中身を削除して、挿入モードに入る
da(     ( ) を、中身ごと削除する
yi{     { } の中身を、コピーする
dit     タグの中身を、削除する
vap     段落を、選択する
```

<pre><code class="tips">ci" や di( は、カーソルが括弧や引用符の中にあれば、動く。先頭に移動する必要はない。
引用符の場合は、同じ行の中で、カーソルより右にある、最初の引用符のペアを探すこともある。</code></pre>

## ドットコマンドと繰り返し <a id="dot-repeat" data-name="繰り返し"></a>

### ドットコマンド

`.` は、**直前の変更**を、繰り返す。挿入した文字列や、動詞と範囲の組み合わせも、1 つの変更として、繰り返せる。

```text
ciwfoo<Esc>    単語を foo に置き換える
w              次の単語へ移動する
.              同じ置き換えを、繰り返す
```

| 繰り返し | キー |
| --- | --- |
| 直前の変更 | `.` |
| 直前の `f` `t` による移動 | `;` / `,` |
| 直前の検索 | `n` / `N` |
| 直前の `:s` | `&` (`g&` は、全体に対して) |
| 直前の Ex コマンド | `@:` |
| レジスタのマクロ | `@{reg}` |

### 回数の指定

| 例 | 内容 |
| --- | --- |
| `3dd` | 3 行を削除する |
| `d3w` | 3 単語を削除する |
| `5i-<Esc>` | `-` を、5 回挿入する |
| `10.` | 直前の変更を、10 回繰り返す |

<pre><code class="tips">編集は、「変更しながら、次の位置へ移動する」形にすると、. で繰り返しやすい。
たとえば、検索 (/pattern) で位置を決めて、cgn で置き換えると、n と . の組み合わせで、一致するたびに、確認しながら置き換えられる。</code></pre>

### cgn による置き換え

```text
/foo<Enter>    foo を検索する
cgnbar<Esc>    最初の一致を、bar に置き換える
.              次の一致を、bar に置き換える
n              置き換えずに、次の一致へ進む
```

`gn` は、次の一致の範囲を選ぶ。`cgn` は、その範囲を変更する。`:s` と違い、**1 つずつ、確認しながら**進められる。

## ビジュアルモード <a id="visual" data-name="ビジュアル"></a>

範囲を選んでから、動詞を、実行する。

| 操作 | 内容 |
| --- | --- |
| `v` + 移動 + `d` | 選んだ範囲を、削除する |
| `V` + `j` + `>` | 選んだ行を、インデントする |
| `viw` | 単語を選択する |
| `vip` | 段落を選択する |
| `gv` | 直前の選択を、もう一度選ぶ |
| `o` | 選択の、反対側の端へ、カーソルを移動する |
| `:` | 選択範囲に対して、Ex コマンドを実行する (`:'<,'>` が、自動で入る) |

### 矩形選択

`CTRL-V` で、長方形の範囲を選ぶ。複数行の、同じ位置に、まとめて入力できる。

```text
CTRL-V  jjj  I// <Esc>     選んだ行の、先頭にコメントを挿入する
CTRL-V  jjj  $A;<Esc>      選んだ行の、末尾に ; を追加する
CTRL-V  jjj  d             矩形の範囲を、削除する
CTRL-V  jjj  c-<Esc>       矩形の範囲を、- に置き換える
```

<pre><code class="caution">矩形選択での I と A は、Esc を押した後に、すべての行へ反映される。入力の途中では、1 行目だけが、変わって見える。
行の長さが違う場合、短い行には、挿入されないことがある。末尾に追加するときは、$ を使う。</code></pre>

## レジスタ <a id="register" data-name="レジスタ"></a>

レジスタは、コピーや削除した内容を、保管する場所である。`"` と名前で指定する。

### 主なレジスタ

| レジスタ | 内容 |
| --- | --- |
| `""` | 無名レジスタ。`d` `c` `y` の、直近の内容 |
| `"0` | 直近の、**ヤンク (`y`)** の内容。削除では、上書きされない |
| `"1`〜`"9` | 削除した内容の、履歴 (行単位の削除など) |
| `"a`〜`"z` | 自由に使える、名前つきレジスタ。大文字で、追記になる |
| `"_` | ブラックホール。書いた内容が、どこにも残らない |
| `"+` | システムのクリップボード |
| `"*` | X11 の、プライマリ選択 (環境による) |
| `".` | 直前に、挿入した文字列 (読み取り専用) |
| `":` | 直前の、Ex コマンド (読み取り専用) |
| `"/` | 直前の、検索パターン |
| `"%` | 現在の、ファイル名 (読み取り専用) |

```text
"ayy      現在の行を、レジスタ a にコピーする
"Ayy      現在の行を、レジスタ a に追記する
"ap       レジスタ a の内容を貼り付ける
"+y       選択範囲を、クリップボードにコピーする
"+p       クリップボードの内容を貼り付ける
"_dd      行を、レジスタを汚さずに削除する
```

```vim
:registers
:reg a 0
```

### 「削除すると、コピーが消える」問題

`dd` や `dw` は、削除した内容を、無名レジスタに入れる。直前にコピーした内容は、無名レジスタ (`""`) から消える。

| やりたいこと | 方法 |
| --- | --- |
| 削除する前の、コピーを貼り付ける | `"0p` |
| 削除しても、コピーを残す | `"_dd` で、削除する |
| 貼り付け先を、置き換える | ビジュアルで選んで、`"0p` |

<pre><code class="caution">"+ と "* は、クリップボードに対応したビルドでしか使えない。vim --version で、+clipboard と表示されるかを確認する。
-clipboard の場合は、"+y を実行しても、システムのクリップボードには、入らない。</code></pre>

<pre><code class="tips">クリップボードを、いつも使いたい場合は、設定に set clipboard=unnamedplus を書く。
ただし、削除のたびに、クリップボードが上書きされる。扱いにくいときは、明示的に "+y を使う。</code></pre>

## 検索 <a id="search" data-name="検索"></a>

### 検索のコマンド

| キー | 内容 |
| --- | --- |
| `/{pattern}` | 前方 (下) へ検索する |
| `?{pattern}` | 後方 (上) へ検索する |
| `n` | 同じ向きに、次の一致へ進む |
| `N` | 逆向きに、次の一致へ進む |
| `*` | カーソルの下の単語を、前方へ検索する (単語単位) |
| `#` | カーソルの下の単語を、後方へ検索する (単語単位) |
| `g*` / `g#` | 単語の一部としても、一致させて検索する |
| `/{pattern}/e` | 一致の、末尾へ移動する |
| `:noh` | 検索結果の、ハイライトを消す |

### 検索の設定

```vim
set incsearch    " 入力しながら、一致を表示する
set hlsearch     " 一致を、ハイライトする
set ignorecase   " 大文字と小文字を、区別しない
set smartcase    " 大文字を含むときだけ、区別する (ignorecase と併用)
set wrapscan     " ファイルの端で、反対側へ回り込む
```

### パターンの書き方

Vim の正規表現は、一般的な正規表現と、**記号のエスケープの規則が違う**。一般的な正規表現の考え方は、正規表現のドキュメントを参照。

| 記号 | 内容 |
| --- | --- |
| `.` | 任意の 1 文字 |
| `*` | 直前の要素の、0 回以上の繰り返し |
| `\+` | 1 回以上の繰り返し |
| `\?` / `\=` | 0 回、または 1 回 |
| `\{n,m}` | `n` 回以上、`m` 回以下の繰り返し |
| `^` / `$` | 行頭、行末 |
| `\<` / `\>` | 単語の、先頭、末尾 |
| `\d` | 数字 |
| `\s` | 空白 |
| `\w` | 単語を構成する文字 |
| `\(...\)` | グループ化 (キャプチャ) |
| `\{-}` | 最短一致の、0 回以上の繰り返し |

標準のモード (magic) では、`+`、`?`、`(`、`)`、`{`、`|` が、**そのままの文字**として扱われる。グループ化や選択には、バックスラッシュが必要になる。

```vim
/foo\(bar\|baz\)
/\v(foo)(bar|baz)
/\<word\>
```

- 2 行目の `\v` は、**very magic** を指定する。記号が、一般的な正規表現に近い意味になり、バックスラッシュが減る。
- `\c` を付けると、大文字と小文字を区別せず、`\C` を付けると、区別する。

<pre><code class="tips">複雑なパターンは、\v を付けて書くと、読みやすい。
検索の履歴は、/ を押した後に、上下のキーで呼び出せる。q/ で、検索履歴のウィンドウを開き、編集して実行することもできる。</code></pre>

## 置換 <a id="substitute" data-name="置換"></a>

### :s コマンド

```vim
:s/old/new/           " 現在の行の、最初の一致を置換する
:s/old/new/g          " 現在の行の、すべての一致を置換する
:%s/old/new/g         " ファイル全体で、置換する
:%s/old/new/gc        " 1 件ずつ、確認しながら置換する
:5,10s/old/new/g      " 5〜10 行目で置換する
:'<,'>s/old/new/g     " 選択範囲で置換する
```

| フラグ | 内容 |
| --- | --- |
| `g` | 行内の、すべての一致を置換する |
| `c` | 置換のたびに、確認する |
| `i` / `I` | 大文字と小文字を、区別しない、する |
| `n` | 置換せずに、一致の数だけを数える |
| `e` | 一致がなくても、エラーにしない |

### 範囲の指定

| 範囲 | 内容 |
| --- | --- |
| `%` | ファイル全体 |
| `.` | 現在の行 |
| `$` | 最終行 |
| `.,$` | 現在の行から、最終行まで |
| `.,+5` | 現在の行から、5 行下まで |
| `/pat1/,/pat2/` | パターンで区切った範囲 |
| `'<,'>` | ビジュアルモードで、選択した範囲 |

### 置換後の文字列

| 記法 | 内容 |
| --- | --- |
| `&` | 一致した文字列全体 |
| `\1`〜`\9` | グループで、キャプチャした文字列 |
| `\r` | 改行 |
| `\n` | 置換後の文字列では、ヌル文字 (改行ではない) |
| `\u` / `\U` | 次の 1 文字、以降を、大文字にする |
| `\l` / `\L` | 次の 1 文字、以降を、小文字にする |
| `\=` | 式の結果で、置き換える |

```vim
:%s/\v(\w+), (\w+)/\2 \1/g           " "Smith, John" を "John Smith" にする
:%s/\<\(\w\)\(\w*\)\>/\u\1\2/g       " 単語の先頭を、大文字にする
:%s/foo/\=line('.')/                 " 一致を、行番号で置き換える
:%s/old/new/gn                       " 置換せずに、一致の数を表示する
```

<pre><code class="caution">置換後の文字列で、改行を入れるときは \r を使う。\n は、ヌル文字になるため、意図した結果にならない。
/ を含むパスを置換するときは、区切り文字を変える。:%s#/usr/local#/opt#g のように、# や + が使える。</code></pre>

<pre><code class="tips">:%s//new/g のように、検索パターンを空にすると、直前の検索パターンが使われる。
先に / で検索して、一致を確認してから、置換すると、安全である。</code></pre>

## バッファ・ウィンドウ・タブ <a id="buffer-window" data-name="バッファ・ウィンドウ・タブ"></a>

### 3 つの概念

| 用語 | 内容 |
| --- | --- |
| バッファ (buffer) | メモリ上に読み込んだ、ファイルの内容 |
| ウィンドウ (window) | バッファを表示する、画面上の領域 |
| タブページ (tab page) | ウィンドウの配置を、まとめたもの |

ウィンドウを閉じても、バッファは、メモリ上に残る。VS Code のような「ファイルごとのタブ」ではなく、**バッファを中心に、使う**のが、Vim の基本である。

### バッファの操作

| コマンド | 内容 |
| --- | --- |
| `:ls` (`:buffers`) | バッファの一覧を表示する |
| `:b {n}` | 番号 `n` のバッファへ切り替える |
| `:b {name}` | 名前の一部で、切り替える |
| `:bn` / `:bp` | 次、前のバッファへ切り替える |
| `:bd` | バッファを削除する (閉じる) |
| `CTRL-^` | 直前に開いていたバッファへ、切り替える |
| `:bufdo {cmd}` | すべてのバッファで、コマンドを実行する |

### ウィンドウの分割と移動

| コマンド | 内容 |
| --- | --- |
| `:sp` / `CTRL-W s` | 上下に分割する |
| `:vsp` / `CTRL-W v` | 左右に分割する |
| `CTRL-W h/j/k/l` | 左、下、上、右のウィンドウへ移動する |
| `CTRL-W w` | 次のウィンドウへ移動する |
| `CTRL-W c` | 現在のウィンドウを閉じる |
| `CTRL-W o` | 現在のウィンドウ以外を、すべて閉じる |
| `CTRL-W =` | ウィンドウの大きさを、均等にする |
| `CTRL-W _` / `CTRL-W <Bar>` | 高さ、幅を、最大にする |
| `CTRL-W H/J/K/L` | ウィンドウを、画面の端へ移動する |

### タブページ

| コマンド | 内容 |
| --- | --- |
| `:tabnew` | 新しいタブを開く |
| `:tabe {file}` | ファイルを、新しいタブで開く |
| `gt` / `gT` | 次、前のタブへ移動する |
| `:tabclose` | タブを閉じる |
| `:tabonly` | 現在のタブ以外を、閉じる |

<pre><code class="caution">:q は、ウィンドウを閉じるコマンドであり、バッファは、メモリに残る。:qa で終了するときに、保存していないバッファがあると、拒否される。
:bd は、バッファを削除する。表示しているウィンドウも、閉じることがある。</code></pre>

## マクロ <a id="macro" data-name="マクロ"></a>

マクロは、キー操作を、レジスタに録画して、再生する機能である。

### 録画と再生

| 操作 | 内容 |
| --- | --- |
| `q{reg}` | レジスタ `reg` への録画を開始する |
| `q` | 録画を終了する |
| `@{reg}` | レジスタ `reg` のマクロを再生する |
| `@@` | 直前に再生した、マクロを再生する |
| `{n}@{reg}` | マクロを、`n` 回再生する |
| `:{range}normal @{reg}` | 範囲の各行で、マクロを再生する |

### 例: 行の先頭に番号を付ける

```text
1. 行頭へ移動して、録画を始める    0qa
2. 行頭に "- " を挿入する          I- <Esc>
3. 次の行へ移動する                j
4. 録画を終える                    q
5. 残りの行へ、再帰せずに、反復する   10@a
```

### 再帰マクロ

録画の最後で、自分自身を呼ぶと、**失敗するまで**、繰り返す。

```text
qaq              レジスタ a を、空にする
qa ... @a q      操作の最後に @a を入れて、録画する
@a               失敗するまで、繰り返す
```

### マクロの編集

マクロは、レジスタの、文字列にすぎない。貼り付けて、編集して、戻せる。

```text
"ap              マクロの内容を、バッファに貼り付ける
(編集する)
"ayy             1 行を、レジスタ a に戻す
```

<pre><code class="tips">マクロは、移動を、f、t、検索、w などの「内容に基づく移動」で書くと、行によって長さが違っても、動く。
10@a のように、多めの回数を指定しても、移動や検索が失敗した時点で、マクロは止まる。</code></pre>

---

## Ex コマンドとグローバルコマンド <a id="ex-command" data-name="Exコマンド"></a>

`:` で入力する、コマンドラインのコマンドを、Ex コマンドと呼ぶ。

### 範囲つきの Ex コマンド

| コマンド | 内容 |
| --- | --- |
| `:{range}d` | 範囲の行を、削除する |
| `:{range}y` | 範囲の行を、コピーする |
| `:{range}m {addr}` | 範囲の行を、`addr` の下へ移動する |
| `:{range}t {addr}` | 範囲の行を、`addr` の下へコピーする (`:t.` は、行の複製) |
| `:{range}>` / `:{range}<` | 範囲の行を、インデントする |
| `:{range}normal {keys}` | 範囲の各行で、ノーマルモードのキーを実行する |
| `:{range}!{cmd}` | 範囲の行を、外部コマンドに通して、置き換える |

```vim
:t.                          " 現在の行を、複製する
:m+1                         " 現在の行を、1 行下へ移動する
:5,10normal I# "             " 5〜10 行目の先頭に、# を挿入する
:%!sort -u                   " ファイル全体を、重複なしで、並べ替える
:'<,'>!jq .                  " 選択範囲の JSON を、整形する
```

### グローバルコマンド

`:g` は、パターンに一致する行に対して、コマンドを実行する。

| コマンド | 内容 |
| --- | --- |
| `:g/{pat}/d` | 一致する行を、すべて削除する |
| `:v/{pat}/d` (`:g!`) | 一致**しない**行を、すべて削除する |
| `:g/{pat}/normal {keys}` | 一致する行で、ノーマルモードのキーを実行する |
| `:g/{pat}/m0` | 一致する行を、先頭へ集める (順序は逆になる) |
| `:g/{pat}/t$` | 一致する行を、末尾へコピーする |
| `:g/{pat}/s/old/new/g` | 一致する行だけで、置換する |

```vim
:g/^$/d                 " 空行を、すべて削除する
:g/TODO/normal A !!!    " TODO を含む行の末尾に、!!! を追加する
:v/error/d              " error を含む行だけを、残す
:g/^/m0                 " 行の順序を、逆にする
```

### コマンドの連結とヒストリ

| 操作 | 内容 |
| --- | --- |
| `:cmd1 <Bar> cmd2` | 複数のコマンドを、1 行に連結する |
| `q:` | コマンドラインの履歴を、ウィンドウで開く |
| `@:` | 直前の Ex コマンドを、再実行する |
| `CTRL-R CTRL-W` | コマンドライン上で、カーソルの下の単語を、挿入する |
| `CTRL-R {reg}` | コマンドライン上で、レジスタの内容を挿入する |

<pre><code class="caution">:g と :normal は、強力である。:g/pattern/d で、意図しない行まで消えても、u で、全体を 1 回で取り消せる。
大きなファイルで試すときは、先に :g/pattern/ だけを実行して、一致する行の一覧を、確認する。</code></pre>

## 補完 <a id="completion" data-name="補完"></a>

挿入モードで、`CTRL-X` を押してから、種類を示すキーを押すと、組み込みの補完が使える。

### 挿入モードの補完

| キー | 内容 |
| --- | --- |
| `CTRL-N` / `CTRL-P` | 次、前の候補で補完する (バッファ内の単語など) |
| `CTRL-X CTRL-F` | ファイル名を補完する |
| `CTRL-X CTRL-L` | 行全体を補完する |
| `CTRL-X CTRL-O` | オムニ補完 (言語ごとの補完) |
| `CTRL-X CTRL-K` | 辞書から補完する |
| `CTRL-X CTRL-]` | タグから補完する |
| `CTRL-X CTRL-R` | レジスタの内容から補完する |
| `CTRL-Y` | 候補を、確定する |
| `CTRL-E` | 補完を、取り消す |

### 補完の設定

```vim
set completeopt=menu,menuone,popup    " 候補が 1 つでも、メニューを出す
set complete=.,w,b,u,t                " 補完の、対象を指定する
```

9.2 では、補完の機能が、大きく拡張された。

| 機能 | 内容 |
| --- | --- |
| `fuzzy` | `'completeopt'` に加えると、あいまい一致で補完する |
| `nosort` | 候補を、並べ替えない |
| `preinsert` | 挿入予定の、テキストを、ハイライトする |
| `nearest` | カーソルからの距離が、近い順に並べる |
| 自動補完 | キー入力なしで、候補を出す機能 (`:help` で、設定を確認する) |

<pre><code class="tips">新しい補完のフラグは、バージョンで増える。使える名前は、:help 'completeopt' で、手元の版のものを確認する。
LSP による補完が必要な場合は、プラグインを入れるか、Neovim の組み込みの LSP を使う。</code></pre>

## マッピング <a id="mapping" data-name="マッピング"></a>

### マッピングのコマンド

モードごとに、コマンドの接頭辞が、違う。

| モード | 再帰あり | 再帰なし |
| --- | --- | --- |
| ノーマル | `nmap` | `nnoremap` |
| 挿入 | `imap` | `inoremap` |
| ビジュアル | `vmap` | `vnoremap` |
| コマンドライン | `cmap` | `cnoremap` |
| すべて (ノーマル、ビジュアル、オペレータ待ち) | `map` | `noremap` |

```vim
nnoremap <Leader>w :w<CR>
nnoremap <Leader>q :q<CR>
inoremap jk <Esc>
nnoremap <C-h> <C-w>h
vnoremap < <gv
vnoremap > >gv
```

### 特殊キーの表記

| 表記 | 内容 |
| --- | --- |
| `<CR>` | Enter |
| `<Esc>` | Esc |
| `<Space>` | スペース |
| `<C-x>` | `CTRL-x` |
| `<A-x>` / `<M-x>` | Alt + x |
| `<Leader>` | リーダーキー。`mapleader` で、指定する |
| `<LocalLeader>` | バッファごとの、リーダーキー |
| `<Bar>` | <code>&#124;</code> (パイプ)。マッピングの中で使う |
| `<silent>` | コマンドの、表示を抑える |

```vim
let mapleader = " "
nnoremap <silent> <Leader>h :nohlsearch<CR>
```

### 再帰なしのマッピングを使う理由

`nmap` は、右辺のキーが、別のマッピングの対象になる。意図しない連鎖や、無限ループを、引き起こすことがある。<br>
**特別な理由がなければ、`noremap` 系を使う**。

### マッピングの確認

| コマンド | 内容 |
| --- | --- |
| `:nmap` | ノーマルモードの、マッピングの一覧 |
| `:verbose nmap {key}` | キーのマッピングが、どこで定義されたかを表示する |
| `:nunmap {key}` | マッピングを、解除する |

<pre><code class="caution">map や nmap は、再帰的に展開される。他のマッピングや、プラグインのマッピングと、衝突すると、予期しない動作になる。
マッピングの末尾に、コメントを書いてはいけない。" 以降も、キーとして、扱われることがある。コメントは、別の行に書く。</code></pre>

<pre><code class="tips">jk や jj で Esc の代わりにする設定は、よく使われる。ただし、j と k を連続して入力したいときに、遅延や誤動作が起きる。
timeoutlen の値で、マッピングの待ち時間を、調整できる。</code></pre>

```bash
git clone https://github.com/example/some-plugin.git \

```

```vim
:packadd optional-plugin
:helptags ALL
```

`:helptags ALL` で、パッケージ内のドキュメントの、タグを生成する。

| --- | --- |

| 名前 | 内容 |
| --- | --- |

<pre><code class="caution">プラグインの多くは、Vim script で書かれていて、Vim の権限で、実行される。信頼できないプラグインを、入れてはいけない。
2026年には、netrw などの、同梱のプラグインでも、脆弱性が報告されて、修正された。更新を、適用する。</code></pre>

## Vim9 script <a id="vim9script" data-name="Vim9script"></a>

Vim9 script は、Vim 9 で導入された、新しいスクリプト言語である。従来の Vim script (レガシー) より、**高速**で、型を持つ。

### 基本

```vim
vim9script

var name: string = "Vim"
const limit: number = 10

def Greet(who: string): string
  return "Hello, " .. who
enddef

echo Greet(name)
```

| 項目 | レガシー Vim script | Vim9 script |
| --- | --- | --- |
| 先頭の宣言 | なし | `vim9script` |
| 変数の宣言 | `let x = 1` | `var x = 1` / `const x = 1` |
| 関数の定義 | `function! F() ... endfunction` | `def F() ... enddef` |
| 型 | なし | 変数や引数に、型を指定できる |
| 文字列の連結 | `.` | `..` |
| コメント | `"` | `#` |

### 9.2 で加わった機能

| 機能 | 内容 |
| --- | --- |
| 列挙型 (enum) | 名前つきの、定数の、集合を定義する |
| ジェネリック関数 | 型を、パラメータにした関数を、定義する |
| タプル型 | 異なる型の値を、まとめて扱う |
| クラスの拡張 | protected なコンストラクタなどが、使えるようになった |

<pre><code class="caution">Vim9 script は、レガシーの Vim script と、構文が違う。vim9script を先頭に書いたファイルでは、let や function! が、使えない。
Neovim は、Vim9 script に対応していない。Neovim でも動かしたいプラグインは、レガシー Vim script か、Lua で書く。</code></pre>


| キー | 内容 |

### quickfix リスト

コンパイルエラーや、検索結果を、一覧にして、順に移動する仕組みである。

| コマンド | 内容 |
| --- | --- |
| `:vimgrep /pat/ **/*.rs` | ファイル群を、検索して、結果を quickfix に入れる |

```vim
:vimgrep /TODO/ **/*.md
```

| `:diffthis` / `:diffoff` | 現在のウィンドウを、diff の対象にする、解除する |

9.2 では、diff に、`linematch` のアルゴリズムが加わった。似た行を、手がかりに、変更を揃えて、表示する。

## セキュリティ <a id="security" data-name="セキュリティ"></a>

### モードライン

ファイルの先頭や末尾に、`vim: set ...:` と書くと、Vim は、そのファイルを開いたときに、オプションを設定する。これを、モードライン (modeline) と呼ぶ。

```text
# vim: set shiftwidth=2 expandtab:
```

モードラインは、信頼できないファイルを開くときに、**攻撃の経路**になる。2026年には、モードライン経由の脆弱性が報告されて、修正された。解説記事によれば、9.2.0350 で、モードラインから変更できるオプションを絞る設定が、既定で有効になった。

| 対策 | 内容 |
| --- | --- |
| Vim を更新する | 修正が入った版を、使う。ディストリビューションの更新も、適用する |
| `set nomodeline` | モードラインを、無効にする |
| `set modelines=0` | モードラインを、探す行数を 0 にする |
| `vim -Z` | 制限モードで、起動する |

### 外部コマンドを実行する機能

| 機能 | 注意点 |
| --- | --- |
| `:!{cmd}` | シェルコマンドを、実行する |
| `system()` | 外部コマンドを、関数から実行する |
| `'shell'` の設定 | 設定によっては、コマンドインジェクションの、影響を受ける |
| 履歴ファイル (`viminfo`) | 悪意のある内容が、後から読み込まれる可能性がある |

<pre><code class="caution">信頼できないファイル (ダウンロードしたソース、他人の設定、ログなど) を開くときは、プラグインとモードラインの影響を、避ける。
vim -u NONE -N file で、設定を読まずに開けば、設定とプラグイン由来のリスクを、減らせる。</code></pre>

## Neovim との違い <a id="neovim" data-name="Neovimとの違い"></a>

Neovim は、Vim をもとに、内部を再構成した、エディタである。Vim のキー操作と、モードの考え方は、ほぼ同じである。

### 主な違い

| | Vim | Neovim |
| --- | --- | --- |
| 設定ファイル | `~/.vimrc` | `~/.config/nvim/init.lua` (または `init.vim`) |
| スクリプト言語 | Vim script、Vim9 script | Lua、Vim script (Vim9 script は、非対応) |
| LSP | プラグインで追加する | 組み込みのクライアントがある |
| プラグイン管理 | パッケージ、外部のマネージャー | 外部のマネージャーに加えて、`vim.pack` (0.12) |
| ターミナル | `:terminal` | `:terminal` (仕組みが、異なる) |
| 非同期処理 | ジョブ、タイマー | ジョブ、タイマー、Lua の API |
| 対象 | どこでも使える、安定した編集環境 | 開発環境として、作り込みやすい |

### Neovim 0.12 の特徴

Neovim 0.12 は、2026年3月に公開された。公式サイトでは、現在の安定版が 0.12 であると、案内されている。

| 機能 | 内容 |
| --- | --- |
| `vim.pack` | 組み込みの、プラグインマネージャー |
| LSP の拡張 | インライン補完、ワークスペース診断、`:lsp` コマンドなどが加わった |
| `ui2` | メッセージとコマンドラインの、新しい UI (実験的)。「Press ENTER」の表示を、減らす |
| プロジェクト設定の信頼 | プロジェクトごとの設定を、明示的に信頼してから、読み込む |

<pre><code class="caution">Neovim は、0.x の番号で、開発が続いていて、版ごとに、破壊的変更がある。古い設定やプラグインは、新しい版で動かないことがある。
Vim の設定を、そのまま、Neovim で使うと、一部が動かない。:help nvim-from-vim で、移行の手順を確認する。</code></pre>

<pre><code class="tips">キー操作の学習は、Vim と Neovim で、ほぼそのまま通用する。まず Vim の基本を覚えて、必要になってから、Neovim の機能を試す、という順序が、無理がない。</code></pre>

## よくある落とし穴 <a id="pitfalls" data-name="よくある落とし穴"></a>

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 文字を入力しても、入力されず、コマンドとして動く | ノーマルモードにいる | `i` を押して、挿入モードに入る |
| 終了できない | モードの、状態が、分からない | `Esc` を押して、`:q!` か `:wq` を実行する |
| `E37: No write since last change` | 変更を保存せずに、終了しようとした | `:w` で保存するか、`:q!` で捨てる |
| `E45: 'readonly' option is set` | 読み取り専用で、開いている | `:w!` を試すか、権限を、確認する |
| `E212: Can't open file for writing` | 書き込みの権限が、ない | 権限を確認する。`sudoedit` で、開き直す |
| 貼り付けた内容が、インデントでずれる | 自動インデントが、貼り付けにも、効いている | `:set paste` を使うか、`"+p` で貼り付ける |
| `"+y` で、クリップボードに入らない | `-clipboard` のビルドである | `vim --version` で確認する。対応版を、入れる |
| 削除すると、コピーした内容が、消える | `d` が、無名レジスタを上書きする | `"0p` を使う。または `"_d` で削除する |
| 置換で、改行されない | `\n` を使っている | 改行は `\r` を使う |
| 置換で、`/` を含む文字列が、使えない | 区切り文字と、衝突している | 区切りを `#` などに、変える |
| 検索のハイライトが、消えない | `hlsearch` が有効である | `:noh` を実行する |
| 設定が、反映されない | 設定ファイルの、場所が、違う | `:echo $MYVIMRC` で、場所を確認する |
| マッピングが、動かない | 他のマッピングと、衝突している | `:verbose nmap {key}` で、定義元を調べる |
| `vim9script` のファイルで、`let` が動かない | 構文が、Vim9 script である | `var` を使う |
| 古い記事の設定が、動かない | 版による、既定値や仕様の、変更 | `:help version-9.2` と、`:help` で確認する |
| 保存後に、`~` のついたファイルや、`.swp` が残る | バックアップと、スワップの設定 | `:set nobackup`、`:set noswapfile` を、検討する |

<pre><code class="caution">.swp ファイルが残っているときは、別の Vim が、同じファイルを開いている可能性がある。確認せずに、削除してはいけない。
クラッシュの後は、Vim が、復元を提案する。内容を確認してから、復元するか、破棄するかを選ぶ。</code></pre>

## 覚え方と、早見表 <a id="cheat" data-name="早見表"></a>

### 学ぶ順序

| 段階 | 内容 |
| --- | --- |
| 1. 最低限 | モードの切り替え、`i`、`Esc`、`:w`、`:q`、`hjkl` |
| 2. 移動 | `w`、`b`、`e`、`0`、`$`、`gg`、`G`、`f`、`t`、`/` |
| 3. 編集 | `d`、`c`、`y`、`p`、`u`、`.`、`dd`、`cc`、`yy` |
| 4. テキストオブジェクト | `ciw`、`ci"`、`di(`、`dap` |
| 5. 検索と置換 | `*`、`n`、`:%s/old/new/g`、`cgn` |
| 6. 効率化 | マクロ、レジスタ、`:g`、`:normal`、マーク |
| 7. 環境 | `.vimrc`、マッピング、プラグイン |

### 組み立ての公式

```text
[回数] 動詞 [回数] 範囲
 2      d     3      w      →  3 単語の削除を、2 回行う (計 6 単語)
        c            i"     →  " の中身を、変更する
        y            ap     →  段落を、コピーする
```

### よく使う操作の早見表

| やりたいこと | キー |
| --- | --- |
| 単語を置き換える | `ciw` |
| 引用符の中身を置き換える | `ci"` |
| 行末に追加する | `A` |
| 行を複製する | `yyp` |
| 行を入れ替える | `ddp` |
| 括弧ごと削除する | `da(` |
| 直前の変更を繰り返す | `.` |
| 次の一致を置き換える | `cgn` と `.` |
| 全体を置換する | `:%s/old/new/g` |
| 行頭に、まとめて挿入する | `CTRL-V` + 選択 + `I` |
| ファイル全体を、インデントする | `gg=G` |
| 全文を、クリップボードへコピーする | `gg"+yG` |
