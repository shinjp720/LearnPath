# re <a id="top" data-name="TOP">

```python
import re
```

### 基本
- 正規表現のパターンにはよくバックスラッシュ(\)が含まれるので、常にraw文字列リテラル形式r'...'で指定するのが得策。
- 正規表現で検索を行うには、主にふたつのアプローチがある。

1. 直接関数にパターンを渡して検索<br>
コンパイルを行わずにパターンを文字列で直接指定する。この方法は単発での検索に便利。
```python
import re
# パターンを文字列で直接指定
text = "There are 123 apples and 456 oranges."
# 直接パターンを渡して検索
m = re.findall(r"\d+", text)
print(m)  # ['123', '456']
```
2. re.compile()でコンパイルしてから検索<br>
最初に正規表現のパターンをコンパイルして、返ってきた正規表現オブジェクトを使って複数回検索を行う。<br>
これにより、同じパターンで繰り返し検索を行う場合に効率的。
```python
import re
# パターンをコンパイル
r = re.compile(r"\d+")
text = "There are 123 apples and 456 oranges."
# コンパイルされたパターンで探索
m = r.findall(text)
print(m)  # ['123', '456']
```

### 正規表現オブジェクトの属性

| 属性名 | 説明 |
| --- | --- |
| flags | compile関数に渡されたflags引数。 |
| groupindex | 要素(?P<id>...)によって定義されたグループ名をキーに持つ辞書。対応する値は指定された名前のグループ番号。 |
| pattern | rのコンパイル元のパターン文字列。 |

正規表現パターン構文
要素	意味
.	\nを除く任意の1文字とマッチする(DOTALLフラグが指定されている場合は\nともマッチする)。
^	文字列の先頭とマッチする(MULTILINEモードでは、\nの直後ともマッチする)。
$	文字列の末尾とマッチする(MULTILINEモードでは、\nの直前ともマッチする)。
*	直前の正規表現を0回以上繰り返しとマッチする。
+	直前の正規表現を1回以上繰り返しとマッチする。
?	直前の正規表現を0回または1回の繰り返しとマッチする。
*?, +?, ??	*、+、?の貪欲ではないマッチング(できるだけ少ない繰り返しとマッチする)。
{m}	直前の正規表現のm回の繰り返しとマッチする。
{m, n}	直前の正規表現のm回からn回の繰り返しとマッチする。mまたはn(またはその両方)を省略してもよい。 デフォルト値はm=0およびn=infinity(貪欲なマッチング)。
{m, n}?	直前の正規表現のm回からn回の繰り返しとマッチする(貪欲ではないマッチング)。
[...]	角括弧で囲まれた文字の集合のいずれかの文字とマッチする。
[^...]	キャレット(^)の後にある文字の集合に含まれていない1文字とマッチする。
|	直前にある正規表現、または直後にある正規表現のいずれかとマッチする。
(...)	丸括弧で囲まれた正規表現とマッチし、グループの始まりと終わりを表す。
(?:...)	(...)と同様だが、グループがマッチした文字列を補足しない。
(?P<id>)	(...)と同様だが、グループがマッチした文字列に<id>という名前でアクセスできる。
(?P=<id>)	<id>という名前のグループが以前にマッチしたものとマッチする。
\number	numberと同じ番号のグループが以前にマッチしたものとマッチする(グループには左から順に1~99の番号が自動的に振られる)。
\A	空の文字列とマッチするが、文字列全体の先頭でのマッチに限られる。
\Z	空の文字列とマッチするが、文字列全体の末尾でのマッチに限られる。
\b	空の文字列とマッチするが、単語の先頭または末尾でのマッチに限られる(単語は英数字の最大シーケンス、\wも参照)。
\d	セット[0-9]と同様に、数字1文字とマッチする。
\D	セット[^0-9]と同様に数字ではない1文字とマッチする。
\N{name}	nameに対応するUnicode文字とまっちする。
\s	セット[\t\n\r\f\v]と同様に、ホワイトスペース文字とマッチする。
\S	セット[^\t\n\r\f\v]と同様に、ホワイトスペースではない文字とマッチする。
\w	セット[a-zA-Z0-9_]と同様に、英数字1文字とマッチする(Unicodeモードであるか、LOCALEまたはUNICODEが設定されていない場合)。
\W	セット[^a-zA-Z0-9_]と同様に、英数字1文字ではない文字とマッチする。
(?aiLmsux)	オプションフラグを設定するもう一つの方法で、常にパターンの先頭に配置する必要がある。
(?#...)	丸括弧で囲まれている内容はコメントとなる。
オプションフラグ
関数compileに対するオプション引数flagsはハードコーディングされた整数であり、ビット論理和で指定する。


import re
re.compile(pattern, flags=re.IGNORECASE|re.MULTILINE)


指定子	意味
IまたはIGNORECASE	マッチングで大文字と小文字を区別しない。
MまたはMULTILINE	特殊文字^と$を、各行の先頭及び末尾(改行の直前と直後)と、文字列全体の先頭および末尾とマッチさせる(\Aと\Zは常に文字列全体の先頭と末尾とのみマッチする)。
SまたはDOTALL	特殊文字.を(改行を含む)任意の文字とマッチさせる。
XまたはVERBOSE	パターンに含まれているホワイトスペースが無視されるようになるが、エスケープされているものと文字の集合に含まれているものを除く。
UまたはUNICODE	\w, \W, \b, \B, \d, \Dに対する文字を決定するためにUnicode全体を使う。ただし、後方互換性を維持するために、このフラグは現在デフォルトとなっている。
AまたはASCII	\w, \W, \b, \B, \d, \Dに対してASCII文字だけを使う。デフォルトのUNICODEフラグを上書きする。
LまたはLOCALE	\w, \W, \b, \B, \d, \Dに対する文字を決定するためにPythonのLOCALE設定を使う。このオプションはbytesのパターンでのみ使うことができる。
compile関数を使って同等の正規表現を定義する方法として次の3つがあるが、読みやすさという点においてはflags引数で明示的に渡す方がよい。


import re
r1 = re.compile(r'(?i)hello')
r2 = re.compile(r'hello', re.I)
r3 = re.compile(r'hello', re.IGNORECASE)
